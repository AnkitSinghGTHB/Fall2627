## 📋 TEE Exam Paper Architecture (Official Format)
* **Duration**: 3 Hours (Closed Book) | **Total Marks**: 100 Marks (Scaled to 30% Weightage)
* **Section A (60 Marks)**: 5 Questions × 12 Marks (1 from each Unit; internal choice `OR` format, either 12M or 6+6M)
* **Section B (40 Marks)**: 5 Questions × 8 Marks (1 from each Unit; direct code/concept question without subparts)
* **Weight Distribution**: Every Unit carries **exactly 20 Marks** (12M in Sec A + 8M in Sec B).

## 🏆 Scoring Rubric for Python Code in Exams
1. **Always write clean, syntactically correct Python 3 code** (use snake_case, correct indentation, and descriptive variable names).
2. **Include output comments** showing sample terminal inputs and outputs.
3. **Handle edge cases** (e.g., file not found with `try-except`, division by zero).
