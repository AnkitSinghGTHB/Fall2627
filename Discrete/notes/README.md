## 📚 How to Use These Notes

1. **Read in order** — Module 1 logic builds into everything else
2. **Do the practice problems** — this subject is 80% practice
3. **Draw the diagrams** — Hasse diagrams, graphs, trees — draw them by hand
4. **Use the cheatsheets** before exams

## 💡 Study Strategy

### The 80/20 Rule:
- **35%** = Logic (truth tables, equivalences, inference) — pure pattern matching
- **25%** = Graphs (degree sequences, Euler/Hamilton, matrix representation)
- **20%** = Relations & Hasse diagrams (draw it → read it → done)
- **20%** = Lattices & Boolean algebra (simplification procedures)
