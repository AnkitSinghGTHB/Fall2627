* **Duration**: 3 Hours (Closed Book) | **Total Marks**: 100 Marks (Scaled to 30% Weightage)
* **Section A (60 Marks)**: 5 Questions × 12 Marks (1 from each Unit; internal choice `OR` format, either 12M or 6+6M)

## 🏆 Scoring Rubric for PAT / Coding Questions in Exams
1. **Always write optimal Time and Space Complexity** at the top of your answer (e.g., Time: $O(N \log N)$, Space: $O(1)$).
2. **Include algorithmic logic in 3–4 bullet points** before writing code.
3. **Provide complete, compilable Java (or C++) code** with proper class and method signatures.
4. **Draw a dry-run execution trace table** on sample inputs.
