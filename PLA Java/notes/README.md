## 💡 Study Strategy for PLA

### The reality:
- **70% of the marks** = Writing correct programs for given problems
- **20% of the marks** = Understanding logic (loops, conditions, recursion, math derivations)
- **10% of the marks** = Theory (Characteristics of an algorithm, Time/Space definitions)

### The approach:
- 🎯 **Understand the Core Patterns** (They repeat the exact same algorithms with different numbers)
- 🎯 **Don't memorize blindly** — understand the *template* and the bitwise / array logic
- 🎯 **Practice writing on paper** — exams are handwritten, not IDE-typed!
