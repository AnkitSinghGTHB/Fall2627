## 🏆 The "Consultant-Grade" Answer Rubric (How to Guarantee 16+/20 per Unit)
Dr. Abhishek Raj and business school evaluators penalize vague essay paragraphs. Full marks are awarded when answers follow this **4-Tier Structured Architecture**:

```
[Question] ──▶ 1. Executive Summary & Core Definition (2 lines)
           ──▶ 2. Comparative Matrix / Framework Diagram (Clean Table or ASCII/Mermaid)
           ──▶ 3. Deep-Dive Analytical Points (Bold Headings + Concrete Startup Examples)
           ──▶ 4. Real-World Business Case Application (e.g., Zomato, Zerodha, Airbnb, Ather)
```

### Essential Exam Golden Rules:
1. **Never write walls of text**: Always use bullet points, tables, and numbered stages.
2. **Always name Indian and Global startup examples**: Zomato (food delivery/customer validation), Zerodha (bootstrapped fintech), Ather Energy (clean-tech hardware incubation), Paytm/PhonePe (UPI tech adoption), Airbnb (asset-light BMC).
3. **In Case Studies**: Explicitly identify the Problem Statement, Stakeholders, Proposed Strategic Framework, Legal/IPR Defense, and Financial Viability.
