Problem 1.3: Arden's Theorem — Statement, Proof & System Solution 12 Marks
Exam Prompt: State and prove Arden's Theorem. Solve the system: q1 = q1 0 + ε, q2 = q1 1 + q2 1, q3 = q2 0 + q3 (0 + 1).

Statement: If P and Q are regular expressions over Σ and P does not contain ε, then the equation R = Q + RP has a unique solution: R = QP*.

Algebraic Proof:
  • Existence: Substitute R = QP* into RHS → RHS = Q + (QP*)P = Q(ε + P*P). Since ε + P*P = P*, RHS = QP* = LHS.
  • Uniqueness: Repeatedly replace R into itself: R = Q + (Q + RP)P = Q + QP + RP^2 = Q(ε + P + P^2 + ... + P^k) + RP^(k+1). Since P has no ε, P^(k+1) contains no strings of length ≤ k. As k → ∞, R = QP*.
System Solution:
1. For q1: q1 = ε + q1 0   ⇒ Q = ε, P = 0 ⇒ q1 = ε·0* = 0*
2. For q2: q2 = (0* 1) + q2 1 ⇒ Q = 0* 1, P = 1 ⇒ q2 = (0* 1) 1* = 0* 1+
3. For q3: q3 = (0* 1+ 0) + q3 (0 + 1) ⇒ q3 = (0* 1+ 0)(0 + 1)*

Problem 2.3: Pumping Lemma Proof for Non-CFL (L = {a^n b^n c^n}) 8 Marks
Proof Strategy: Assume L is CFL with pumping length p. Choose string z = a^p b^p c^p (|z| = 3p ≥ p). By CFL Pumping Lemma, z = uvwxy with |vwx| ≤ p and |vx| ≥ 1.

5-Case Breakdown: Because |vwx| ≤ p, the substring vwx cannot contain all three symbols a, b, and c simultaneously. Therefore, vx contains at most two distinct symbols:

  • If vx contains only a's and b's, pumping down (i = 0) reduces the number of a's or b's, but leaves the count of c's unchanged at p. Thus, the counts are no longer equal.
  • If vx contains only b's and c's, pumping down (i = 0) leaves the count of a's unchanged at p.

In all cases, u v^0 w x^0 y ∉ L. Contradiction! ∴ L is NOT context-free. (Q.E.D.)

Problem 4.2: Halting Problem (HALT_TM) Undecidability Proof 12 Marks / 8 Marks
Theorem: HALT_TM = { ⟨M, w⟩ | Turing Machine M halts on input w } is undecidable.

Proof by Diagonalization:

  • Assume decider H(⟨M, w⟩) exists: H accepts if M halts on w; H rejects if M loops on w.
  • Construct adversarial machine D(⟨M⟩): Run H(⟨M, ⟨M⟩⟩). If H accepts, D loops infinitely. If H rejects, D halts.
  • Pass description of D to itself: D(⟨D⟩):
    • If D halts on ⟨D⟩ ⇒ D must loop infinitely!
    • If D loops on ⟨D⟩ ⇒ D must halt!
  • Contradiction: D halts on ⟨D⟩ ⇔ D does not halt on ⟨D⟩.
  • ∴ Decider H cannot exist ⇒ HALT_TM is UNDECIDABLE. (Q.E.D.)
