## 💡 Top Exam Hall Rules for Tomorrow
1. **Read Single Choice vs Multiple Select (MSQ) Carefully**:
   * NPTEL includes both MCQ (single correct) and MSQ (one or more correct options). If a question says *"Which of the following are characteristics..."*, select all valid statements!
2. **Beware of Negative Statements**:
   * Watch out for phrases like *"Which of the following is NOT true"*, *"Which of the following does NOT have a network layer"* (Wired HART!).
3. **No Negative Marking in Most Objective Sections**:
   * Attempt **100% of the questions**! Never leave any question unanswered.
